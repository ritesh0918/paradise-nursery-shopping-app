# Paradise Nursery Shopping Application

## Project Overview

Paradise Nursery is a React-based online plant shopping application. It allows users to browse houseplants, view product prices, add plants to a shopping cart, change quantities, and calculate the total cost of their purchases.

## Features

- Responsive landing page
- Plant catalogue with categories, images, names, and prices
- Add-to-cart functionality
- Shopping cart with quantity controls
- Remove items from the cart
- Automatic price calculations
- Checkout message

## Technologies Used

- React
- JavaScript
- CSS
- Redux Toolkit
- React Redux
- Vite

## How to Run

1. Install Node.js.
2. Install project dependencies using `npm install`.
3. Start the development server using `npm run dev`.
